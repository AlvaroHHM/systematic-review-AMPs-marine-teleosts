# 05. Risk of Bias Assessment

Adapted transcriptomic quality framework (MINSEQE + BUSCO).

## Five Domains

1. Biological replication (n >= 3)
2. Public repository deposition (SRA, ENA, DDBJ, GEO)
3. Sequencing depth and BUSCO completeness (>80% actinopterygii_odb10)
4. Experimental validation (qRT-PCR, MIC, recombinant, immunolocalization)
5. Experimental design and controls
